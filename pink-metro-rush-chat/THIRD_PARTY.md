# Third-party assets

Pink Metro Rush is a separate chat-side prototype built from legally reusable assets plus original game logic.

## Runner base
- KayKit Character Pack: Adventures
- Asset used: Rogue.glb + rogue_texture.png
- Source: KayKit Game Assets
- License: CC0 1.0

The runtime recolors and augments the rigged base with an original pink-feline head, sunglasses, cap, long tail, and board. It does not include the official Pink Panther character model.

## Railway / train assets
- Kenney Train Kit
- Assets used include subway/city/bullet train models and railroad-straight geometry
- License: CC0 1.0

## City assets
- Kenney City Kit Suburban
- Kenney City Kit Roads props
- License: CC0 1.0

Music and sound effects are generated procedurally by generate_audio.py.
