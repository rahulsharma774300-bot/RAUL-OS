# Third-party assets

This project downloads the following CC0 assets during the GitHub Actions build.

## Animated character base
- Astronaut_RaeTheRedPanda from Quaternius Ultimate Space Kit
- Source copy: danvanderboom/Aetherium
- License: CC0 1.0

The game tints/customizes the model and adds original pink-feline accessories. It is not distributed as the Pink Panther trademarked character.

## City / street models
- Kenney City Kit Suburban and City Kit Roads
- Source copy: petroulacl/fps-buildings-env-kit
- License: CC0 1.0

Music and sound effects are generated procedurally by generate_audio.py.
